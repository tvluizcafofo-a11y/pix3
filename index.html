Como usar o PIX3

  • 1. Cadastre um recebedor
    Clique em "✎ Editar" no resumo e preencha nome, cidade e pelo menos uma chave PIX. Crie uma senha para proteger a edição.
  • 2. Gerar cobrança
    Informe o valor, opcionalmente uma descrição, e clique em "⚡ Gerar QR Code PIX".
  • 3. Compartilhar
    Copie o código ou compartilhe via WhatsApp/e-mail. O destinatário cola no app do banco.
  • 4. Recebimento automático
    Quando o Pix cair, o app detecta, mostra o aviso e registra automaticamente. Se o valor bater com uma cobrança pendente, ela é marcada como paga.
  • 5. Gerenciar bancos
    O app já reconhece BB, Mercado Pago, Sicoob, XP e Nubank. Se aparecer outro banco, use "🧠 Bancos" para ensinar o formato.
  • 6. Esqueceu a senha?
    Na tela de login, clique em "Esqueci minha senha" e use o código de recuperação.
